# TI-Nspire CX II CAS Study and Chat Assistant

This offline AI tool is designed for studying and casual conversation.

**Do not use this tool to cheat on exams, including the AP exams or the SAT. It is a study aid, not a tool for academic misconduct.**

## How to Use

1. Type `help` to see the assistant's main features.
2. In the Python Shell, run `main()` to start the chat.
3. Type `quit()` to end the chat. You can also type `quit`, `exit`, `bye`, or `goodbye`.
4. Approximate a derivative with `fnDiff(expression, point, variable)`. For example, `fnDiff(x^2, 3, x)` estimates the derivative of `x^2` at `x = 3`.
5. Approximate a definite integral with `fnInt(expression, lower, upper, variable)`. For example, `fnInt(x^2, 0, 5, x)` estimates the integral of `x^2` from 0 to 5.
6. You can also describe a math task in plain English. For example, `calculate the area under x squared from 1 to 6` is interpreted as a definite integral. Clear bounds are required; if you say only `interval 126`, the assistant will ask you to clarify instead of guessing.
7. Basic spoken arithmetic is supported, such as `what is five plus three?`, `calculate 8 divided by 2`, or `compute 3 times 4`.
8. Some statistics questions are recognized in plain English, such as `what is the mean of 2, 4, 6?` or `what is the standard deviation of 2, 4, 6?`.

The derivative and integral commands use numerical methods, so their results are approximations. The assistant uses fixed English patterns and is not a general-purpose language model.
